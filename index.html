Masalahnya

Mengelola event besar tanpa sistem itu melelahkan.

Data tamu berserakan

Daftar tamu tersebar di Excel, chat WhatsApp, dan catatan kertas. Susah dicari, rawan dobel, gampang hilang.

Atur meja serba manual

Menggambar denah meja di kertas, bingung siapa duduk di mana, repot kalau ada perubahan mendadak.

Rundown kacau di lapangan

Crew tidak tahu acara sampai mana. Koordinasi pakai teriakan dan HT yang simpang-siur.

“Satu kesalahan kecil di hari-H bisa merusak reputasi yang Anda bangun bertahun-tahun.”

Solusinya

Satu sistem. Semua tim. Satu sumber kebenaran.

Acarani menyatukan admin, pagar ayu, crew, hingga klien dalam satu sistem yang sama — data selalu sinkron sepanjang acara berlangsung.

Terpusat

Semua data acara di satu tempat, bukan tersebar di banyak file.

Real-time

Perubahan langsung terlihat seluruh tim saat itu juga.

Milik Anda

Terpasang di server Anda. Tidak menumpang server pihak ketiga.

Fitur Unggulan

Semua yang Anda butuhkan untuk menjalankan acara.

01 — Manajemen Multi-Event

Kelola banyak acara dari satu dashboard

Setiap event punya tamu, meja, rundown, dan timnya sendiri — rapi dan tidak pernah tercampur.

  • Pantau status tiap acara sekilas
  • Kode event unik & otomatis
02 — Manajemen Tamu

Import ratusan tamu sekaligus dari Excel

Tambah satu per satu atau import massal. Kelompokkan per kategori dan per sisi pengantin, lengkap dengan jumlah pax undangan.

  • Import Excel sekali klik
  • QR code unik tiap tamu
03 — Denah Meja Interaktif

Atur posisi meja dengan drag & drop

Susun denah persis seperti venue aslinya. Tempatkan tamu ke meja, lihat kapasitas, dan cetak denah untuk tim di lapangan.

  • Auto-save & sinkron real-time
  • Status meja: kosong / sebagian / penuh
04 — Desainer Kartu Meja

Rancang & cetak kartu tamu langsung dari sistem

Tidak perlu desain manual satu per satu. Atur posisi field, pakai background sendiri, lalu generate massal — siap cetak.

  • Ukuran kartu custom (mm)
  • Cetak massal siap percetakan
05 — Rundown & Crew Real-Time

Seluruh crew selalu satu langkah

Susun rundown dari template siap pakai, lalu jalankan di hari-H. Crew melihat update rundown langsung di layar mereka.

  • Template rundown reusable
  • Update tersiar real-time ke crew
06 — Laporan Lengkap

Semua terekam dalam angka

Pantau kehadiran, log check-in, rekap angpao, dan ringkasan acara. Siap dipresentasikan ke klien setelah acara selesai.

  • Rekap kehadiran & angpao
  • Ringkasan event sekali lihat
